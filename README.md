# Sweet Moment Chocolates - Static Website

This is a complete static website for Sweet Moment Chocolates, generated from real data.

## Files Included:
- index.html - Home page with hero section and featured products
- menu.html - Complete product catalog
- product-{product-name}.html - Individual product detail pages (5 pages)
  - Product pages use SEO-friendly URLs based on product names
- about.html - Company information and story
- contact.html - Contact information and form
- uploads/ - Real product images

## Features:
- Responsive design using Tailwind CSS
- Real product data and images with correct pricing
- SEO-friendly URLs for product pages
- Payment redirect integration (configurable in admin panel)
- Authentic business information for Herndon, VA location
- Multi-page navigation
- Professional styling matching the main site

## Deployment:
1. Upload all files to your web server or GitHub Pages
2. Ensure the uploads folder is accessible
3. For GitHub Pages subdirectory deployment, update basePath in the generator
4. The site will work on any standard web hosting platform

## Payment Redirect:
- Configure payment redirect URL in the main site's admin panel
- Product details (name, price, ID) are automatically passed as URL parameters
- Opens payment page in new tab for seamless checkout experience
